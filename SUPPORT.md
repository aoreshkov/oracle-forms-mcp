# Getting help

- **Installing and configuring:** start with the [README](README.md) and the [guide](guide/).
- **Questions and ideas:** ask in
  [Discussions](https://github.com/aoreshkov/oracle-forms-mcp/discussions).
- **Bugs and feature requests:** open an
  [issue](https://github.com/aoreshkov/oracle-forms-mcp/issues/new/choose) using one of the forms.
- **Security vulnerabilities:** don't open a public issue. Follow [SECURITY.md](SECURITY.md).
